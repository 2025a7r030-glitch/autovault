Active Protection: OWASP Top 10 Aligned

Cryptographic Password Hashing

Passwords are never stored in plaintext. Werkzeug uses the modern scrypt / pbkdf2:sha256 algorithm with per-user cryptographic salts to resist dictionary & rainbow table attacks.

NIST SP 800-63B

IDOR & Access Control

Prevents Insecure Direct Object References (OWASP A01:2021). All queries for vehicles, fuel logs, and service records strictly filter by session['user_id'] and verify asset ownership.

OWASP A01: Broken Access Control

SQL Injection Immunity

AutoVault utilizes SQLAlchemy ORM with strictly parameterized queries. Raw string concatenation is eliminated, ensuring user inputs are treated solely as literal values by SQLite.

OWASP A03: Injection

Hardened Session Cookies

Sessions employ HttpOnly=True (preventing client-side JavaScript theft via XSS) and SameSite=Lax (mitigating Cross-Site Request Forgery / CSRF vulnerabilities).

Session Hardening
